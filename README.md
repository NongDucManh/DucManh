# Đức Mạnh - GitHub Pages

## Cấu trúc
- `index.html`: trang chính
- `style.css`: giao diện
- `script.js`: lưu vCard, chia sẻ và tạo QR trang
- `Duc-Manh.vcf`: danh bạ vCard
- `assets/avatar.jpg`: ảnh đại diện
- `assets/bank-qr.jpg`: QR thanh toán Techcombank

## Đưa lên GitHub Pages
1. Tạo repository mới trên GitHub, ví dụ `duc-manh`.
2. Upload toàn bộ file/thư mục trong bộ source này.
3. Vào **Settings → Pages**.
4. Chọn **Deploy from a branch** → branch `main` → folder `/root` → **Save**.
5. Mở URL GitHub Pages được GitHub cấp.

QR "TRANG DỊCH VỤ" sẽ tự động lấy đúng URL hiện tại sau khi trang được mở.

## Thêm Facebook
Trong `index.html`, tìm:
`https://www.facebook.com/YOUR_FACEBOOK`

và thay bằng link Facebook cá nhân của bạn, ví dụ:
`https://www.facebook.com/tenban`

Không cần sửa `style.css`.
